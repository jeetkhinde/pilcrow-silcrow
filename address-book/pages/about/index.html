About Pilcrow Contacts

This is the React Router address book tutorial recast as a Pilcrow and Silcrow app. It keeps the same product surface: nested routes, URL params, server data loading, form mutations, redirects, search params, active links, pending UI, and optimistic feedback.

Framework DX on Display

  • File-system routing maps folders like contacts/[contact_id] directly to URLs.
  • Each HTML template sits beside a Rust code-behind file with typed Props, load, and named actions.
  • Silcrow attributes progressively enhance normal links and forms.
  • FSR registers SQL-backed live slots in pilcrow_fsr and can bake promoted HTML/JSON artifacts.
