Slice D — Final Design

All decisions locked. Review before spec is written.

#5 — Global Boost (s-boost REMOVED)

Every <a href> is boosted. No container needed.

<!-- just works -->
<a href="/dashboard">Go</a>

<!-- opt-out -->
<a href="/pdf" no-boost>PDF</a>

<!-- partial swap via s-target -->
<div s-target="#detail">
  <a href="/t/1">Ticket 1</a>
</div>

Auto-skip rules (safety):

no-boost→ skip
External origin→ skip
download→ skip
target="_blank"→ skip
href="#…"→ skip
mailto: / tel:→ skip

Target resolution:
1. anchor[s-target]
2. closest("[s-target]")
3. document.body

#6 — Three-Mode Navigation

Server signals mode via response header. Client uses s-target for WHERE.

full No header. Full page HTML. Target = body.
fragment X-Pilcrow-Layout: fragment. Partial HTML (no shell). Target = s-target.
json X-Pilcrow-Layout: json. Props JSON. Patched in-place. Target = s-target.

data-ps-slot dropped. s-target is the only targeting mechanism.

#7 — Scroll per mode
full window.scrollTo(0,0)
fragment target = body → scroll top; target = element → no scroll (panel already visible)
json Preserve scroll position

Popstate: always restore history.state.scrollY regardless of mode.

#8 — <pilcrow:head> on all nav

Codegen prepends to every page body:

<template data-ps-head>
  <title>{{ props.title }}</title>
  <meta name="description" …>
</template>

Fragment: extract template.content, upsert into document.head
JSON: server adds __ps_head string to props payload; client parses + applies
Upsert rules: title, meta[name], meta[property], link[rel=canonical]

#9 — History stores layout hash

Codegen emits fingerprint on <body>:

<body data-ps-layout="a3f7c2">

Hash = short hash of layout chain file paths (build-time constant). On pushState: include { layoutHash, scrollY, url }. Enables popstate to know which mode was active.

#10 — View Transitions (all modes)
if (document.startViewTransition) {
  document.startViewTransition(() => proceed());
} else {
  proceed(); // graceful fallback
}

Wraps all three modes uniformly. Developer controls animation via CSS @view-transition rules. No Silcrow config needed.
