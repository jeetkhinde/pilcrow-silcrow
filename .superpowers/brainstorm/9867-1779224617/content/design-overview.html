TODO #6 — Three-mode navigation

Server decides. Signals via response header. Codegen emits slot markers.

# Response headers (server → client)
X-Pilcrow-Layout: full (default)
X-Pilcrow-Layout: fragment (main slot only)
X-Pilcrow-Layout: json (props JSON)

Codegen wraps default-slot content: <div data-ps-slot="main">…</div>

TODO #7 — Scroll per mode
full→ window.scrollTo(0,0)
fragment→ [data-ps-slot="main"].scrollIntoView()
json→ preserve (no scroll)

All three modes still save/restore scroll on popstate via history.state.scrollY

TODO #8 — <pilcrow:head> on all nav modes

Codegen always prepends to body:

<template data-ps-head>
  <title>{{ props.title }}</title>
  <meta name="description" …>
</template>

Fragment: Silcrow extracts template.content and upserts nodes into document.head.
JSON: server includes "__ps_head": "<title>…</title>" in props payload.

TODO #9 — History stores layout hash

Codegen emits layout fingerprint on <body>:

<body data-ps-layout="a3f7c2">

On navigation: history.pushState({ …, layoutHash: "a3f7c2" }). On popstate: Silcrow knows which mode was active for that page. Hash is a short hash of the layout chain file paths.

TODO #10 — View Transitions

Wraps all three modes uniformly:

// in navigate(), around the swap:
if (document.startViewTransition) {
  document.startViewTransition(() => proceed());
} else {
  proceed();
}

Graceful fallback: no transition if API unavailable. Works with CSS @view-transition rules the developer defines.

Full navigation flow (boosted GET)
1. User clicks <a> inside [s-boost] container
2. isSafeBoostHref() passes (not external / download / hash / s-boost="false")
3. fetch(url, { headers: { "silcrow-target": "true" } })
4. Server sees silcrow-target → consults route config → sets X-Pilcrow-Layout header
5. Silcrow reads header → chooses swap strategy
   full: safeSetHTML(document.body, html) → scrollTo(0,0)
   fragment: safeSetHTML(slot, html) + applyHead(template) → slot.scrollIntoView()
   json: patch(data, slot) + applyHead(data.__ps_head) → preserve scroll
6. document.startViewTransition() wraps step 5
7. history.pushState({ layoutHash, scrollY, url })
8. silcrow:load event dispatched
