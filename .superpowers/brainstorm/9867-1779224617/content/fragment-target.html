Implication for data-ps-slot
A

Drop data-ps-slot entirely

Fragment nav always uses s-target (same as today). No codegen change needed for slot markers. X-Pilcrow-Layout only signals response shape — not target.

B

Keep data-ps-slot as fallback default

If no s-target is set on a boost element, Silcrow looks for [data-ps-slot="main"] as the default swap target instead of document.body. Developer opts in by putting it in their layout. s-target always wins when present.
