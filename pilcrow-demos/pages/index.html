Pilcrow Rendering Models

Each page below is a live, working demo built with Pilcrow — the same framework rendering this page. Every demo shows its own source code so you can see exactly how the rendering model is implemented.

SSR

Server-Side Rendering

load() runs on every request. No caching. The counter increments on every visit.

 ISR

Incremental SSR

Stale-while-revalidate cache. REVALIDATE = 10 — watch the timestamp freeze between requests.

 SSG

Static Site Generation

PRERENDER = true — rendered once at server startup. Timestamp never changes.

 ISR+SSG

Startup-warm ISR

Pre-rendered at startup and revalidated on a TTL — best of both worlds.

 Streaming

SSR Streaming

Shell arrives in ~0ms. load() runs in background — watch the page patch itself.

 Deferred

Deferred Fields

Deferred<T> and DeferredHtml — per-field streaming, works with ISR.
