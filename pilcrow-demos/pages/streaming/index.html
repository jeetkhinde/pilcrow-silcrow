Template rule: Use :text="field" (Silcrow binding) for any field that should update after the shell renders. Using {% raw %}{{ field }}{% endraw %} (Askama interpolation) bakes the default value into the HTML and the stream patch cannot update it. The Default impl sets "Loading…" strings that appear in the shell.
How it works:
  1. Layout load() runs (none here)
  2. Shell rendered with Props::default() — "Loading…" values sent immediately
  3. A window.__ps shim is injected before </head>
  4. load() spawns on tokio::spawn (600ms sleep simulates slow I/O)
  5. When load() resolves, Props is serialised and streamed as window.__ps({...})
  6. Silcrow patches all :text bindings in the DOM
