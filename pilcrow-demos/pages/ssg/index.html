Reload as many times as you like — the values never change while the server is running. Restart the server to see them update.

How it works: pub const PRERENDER: bool = true; tells routekit to include this page in __pilcrow_prerender_all(), called by pilcrow_start() before the server accepts connections. The result is stored in the ISR cache with a u64::MAX TTL — it never expires. Every subsequent request hits the cache and never calls load() again.
Note: PRERENDER is a no-op for pages without load() (they're already static) and for pages with Deferred<T> or DeferredHtml fields. Use ISR+SSG if you need the cache to refresh over time.
